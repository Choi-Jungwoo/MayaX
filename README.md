# MayaX

MayaX is a example runtime for Autodesk Maya.

## Supported Platform

- Windows

## Supported Maya Version

- 2018 (This Example)
- ALL

## Features

- Hook API Example
- Call Maya C++ API Example
- Ignore ScriptNode Example

## Build

```bash
cargo build --release
```

## Run

You must set `MAYA_PATH` environment variable to the path of the Maya installation.

```bash
cargo run
```
